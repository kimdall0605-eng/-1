✧ 쿠리만쥬 이용약관 ✧

마지막 수정: 2026-11-14 / 쿠리만쥬 보안봇

쿠리만쥬를 서버에 초대하면 이 약관에 동의한 거야. 길게 안 쓸게, 핵심만 읽어봐.

1. 쿠리만쥬가 하는 일

서버 보안만 해. 스팸, 스캠, 도배, 테러, 관리자 탈취, 초대링크, 욕설 같은 거 막고, 테러나면 백업으로 복구해줘.

2. 수집하는 거

  • 서버 ID, 채널 ID, 유저 ID (보안 로그용)
  • 차단 / 격리 / 경고 기록
  • 설정값 (뭐 켰는지)

DM 내용은 안 봐. 토큰은 절대 안 저장해.

3. 안 하는 거

  • 유저 메시지 팔아서 돈 벌기 ❌
  • DM 몰래 읽기 ❌
  • 다른 서버에 네 정보 공유 ❌

4. 관리자 책임

봇 권한을 최상위로 올려줘야 제대로 막아. 관리자 계정 털리면 쿠리만쥬도 못 막을 수 있어. 계정은 꼭 2차 인증 켜놔.

5. 책임 한계

쿠리만쥬는 최선을 다해서 막지만 100%는 아니야. 서버 관리 최종 책임은 서버 주인한테 있어. 테러나면 /복구로 백업 복구해줘.

6. 문의 / 삭제 요청

봇을 서버에서 내보내면 그 서버 데이터는 더 안 써. 데이터 삭제 원하면 디스코드에서 쿠리만쥬 개발자에게 문의해줘.
